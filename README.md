🧠 1. Project Title & Description

Sales Forecasting System
A machine learning-based solution that predicts sales, segments customers, and maximizes profit using real company data. Includes ML models (XGBoost, Prophet, K-Means) and an interactive Power BI & Next.js dashboard.

⚙️ 2. Technologies Used

Python, Pandas, NumPy, Scikit-learn, XGBoost, Prophet, Random Forest, K-Means, Flask, Next.js, Power BI, Matplotlib, Seaborn, Plotly.js, Jupyter Notebook, VS Code, Git, GitHub, Excel.

📈 3. Features

Sales forecasting using XGBoost and Prophet (MAPE < 10%)

Customer segmentation via K-Means (Silhouette > 0.6)

Churn detection using XGBoost (AUC > 0.85)

Power BI dashboard for revenue, regions, and product performance

Next.js + Flask integration for real-time insights
